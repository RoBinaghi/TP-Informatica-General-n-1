Desarrollo del Proyecto

La plataforma es una aplicación web interactiva desarrollada con HTML5, CSS3 y JavaScript nativo (Vanilla JS). Integra tres juegos interactivos diferentes y un módulo centralizado de puntuaciones:

21 con Dados

Juego de estrategia en el que los jugadores tiran dos dados intentando acercarse lo más posible a 21 puntos sin pasarse. Incluye reglas especiales (Suma estándar, Pares Iguales, Doble As y Puntas) y soporte para jugar contra la computadora o más participantes.

Casita Robada

Implementación interactiva del clásico juego de cartas. Permite realizar capturas desde la mesa central o robar la pila ("casita") de las cartas acumuladas por los oponentes.

Cinefilia Trivia

Juego de preguntas y respuestas temático sobre cine para poner a prueba los conocimientos del usuario y sumar puntos en base a las respuestas correctas.
API utilizada: The Movie Database (TMDB) API

Sistema de Puntajes y Registros

Módulo de almacenamiento que centraliza las puntuaciones históricas de todos los juegos utilizando localStorage (Web Storage) Permite listar las posiciones de mayor a menor con formato ordinal (1°, 2°, 3°...) y filtrar participantes.

Metodología y Control de Versiones

Para la realización de este proyecto en conjunto se aplicaron prácticas de desarrollo colaborativo mediante Git y GitHub:

  • Repositorio compartido: Configuración del repositorio remoto con asignación de colaboradores.
  • Flujo de trabajo: Aplicación constante del ciclo de trabajo en equipo: pull → trabajo local → add → commit → push
  • Consumo de APIs: Integración dinámica mediante peticiones asíncronas con fetch() a la API de TMDB.
  • Uso de IA como guía: Apoyo en modelos de Inteligencia Artificial para la resolución de dudas lógicas, optimización de algoritmos y estandarización del código.
